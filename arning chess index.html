LESSON 1

📁 Files (Vertical Columns)

The chess board has 8 vertical columns called Files. They are named with lowercase letters from left to right: a, b, c, d, e, f, g, h (from White's perspective).

LESSON 2

🔢 Ranks (Horizontal Rows)

The 8 horizontal rows are called Ranks. They are numbered 1 to 8. White's main army starts on rank 1, White pawns on rank 2. Black's pawns start on rank 7 and main pieces on rank 8.

LESSON 3

📍 Identifying Any Square

Every square is the intersection of its File + Rank. For instance, the file e and rank 4 cross at e4. Always write the file letter first, followed by the rank number!

LESSON 4

🛡️ Golden Rules for Speed

1. "White on Right": The bottom-right corner is always a light square (h1 for White, a8 for Black).
2. Central Squares: d4, d5, e4, e5 control the center of the board.
3. Even ranks on the same file alternate colors!
